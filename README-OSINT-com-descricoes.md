# 🕵️ Repositório de Ferramentas OSINT

Uma coleção de ferramentas, plataformas e fontes abertas para apoiar atividades de **OSINT (Open Source Intelligence)** — inteligência baseada em informações disponíveis publicamente.

O objetivo deste repositório é reunir recursos de pesquisa, análise, verificação e documentação em um só lugar, organizados por categoria.

> **Uso responsável:** consulte apenas informações que você tenha autorização ou finalidade legítima para pesquisar. Respeite a privacidade, os termos de uso de cada serviço e a legislação aplicável, incluindo a LGPD. Não utilize essas ferramentas para perseguição, assédio, exposição indevida, invasão de contas ou obtenção não autorizada de dados.

## 📚 Sobre OSINT

OSINT é o processo de localizar, coletar, analisar e verificar informações obtidas de fontes abertas. A ferramenta adequada depende da pergunta de pesquisa e do contexto de uso.
