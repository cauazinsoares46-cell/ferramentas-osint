> **Uso responsável:** utilize estas ferramentas apenas para fins legítimos, respeitando a legislação aplicável, a LGPD e a privacidade de terceiros. Não use informações obtidas para assédio, perseguição, invasão de contas ou exposição indevida de pessoas.
